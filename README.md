# Scene Prefabs (Foundry VTT Module)

Модуль инициализирован как заготовка для Foundry VTT **v13.351**.

## Структура

- `module.json` — манифест модуля.
- `scripts/main.js` — точка входа JavaScript (ESModule).
- `styles/module.css` — стили для интерфейса модуля.

## Установка

1. Убедитесь, что эта папка находится в каталоге `Data/modules/scene-prefabs` вашего Foundry VTT.
2. Перезапустите Foundry VTT.
3. В меню **Настройки → Управление модулями** включите модуль **Scene Prefabs**.
